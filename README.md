# DayZ World Cup Gear

This is the source of the [DayZ World Cup Gear](https://steamcommunity.com/sharedfiles/filedetails/?id=3734555901) mod.

This mod was created for the DayZ World Cup event by [hitty](https://www.twitch.tv/hittty)

## Contents

This mod contains a special event t-shirt, and a tactial helmet, plate carrier, pouches and assault bag using the flag for each of these countries:

- Brazil
- Canada
- Denmark
- England
- France
- Ireland
- Italy
- Portugal
- Scotland
- South Africa
- South Korea
- Sweeden
- USA
- Wales
- Russia


## Building

This mod uses [dayz-mod-build](https://github.com/jmhobbs/dayz-mod-build) to pre-process it's files.

1. Download this repository
2. Run `dayz-mod-build.exe DayZ-World-Cup-Gear`
3. It will create `P:\DayZ-World-Cup-Gear` and convert/copy files as needed
4. Run the Addon Builder on `P:\Dayz-World-Cup-Gear`
5. Any changes you make, do so in the git repository and re-run `dayz-mod-build.exe`.
